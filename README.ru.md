# Botile

[English version](README.md)

Botile рисует аватары Telegram-ботов как скруглённые квадраты с тонкой
адаптивной обводкой. Обычные пользователи, группы, каналы и пользовательские
изображения сохраняют радиус, выбранный клиентом.

Текущая версия: **1.2.0**.

## Установка

1. Установите `Botile-<version>.plugin` из релиза или `Botile.plugin` из
   checkout. Релизный файл побайтово совпадает с `Botile.plugin`; при наличии
   проверьте его по `SHA256SUMS`.
2. В окне установки выберите **Java hooks (full control)** и оставьте Botile
   на уровне **Trusted**. Без разрешения `hooks` плагин неактивен.
3. Включите Botile и убедитесь, что журнал начинается с
   `Botile 1.2.0 starting`.
4. Если установлен старый файл Botile, удалите его и установите новый заново.

Root, LSPosed, модификация APK, сеть и дополнительные Python-пакеты не нужны.
Единственное объявленное разрешение — `hooks`.

## Совместимость

- exteraless `>= 12.10.6`
- SDK плагинов `>= 1.4.5.3`

Целевые методы и сигнатуры проверены на exteraless `12.10.6-00c14f4`
(SDK `1.4.5.3`). Та же поверхность хуков проверена в текущем исходнике
(`13.0.2`, SDK `1.4.5.7`), поэтому заявленный диапазон совместим по исходному
коду. Это не означает, что каждая поверхность UI проверена на каждой сборке.

## Настройки рамки

Откройте **Настройки → Плагины → Botile**. Экран следует активному языку
exteraless (`LocaleController.getLocaleStringIso639()`): русский для русского
языка клиента, иначе английский. Для оформления используются документированные
`SimpleSettingFactory`/`Custom`:

- **Показывать рамку** — включена по умолчанию, поведение 1.1.3 сохранено.
- **Цвет рамки** — настоящая палитра с образцами: адаптивная `Тема`, `Акцент`,
  `Белая` и `Чёрная`. Образцы «Тема» и «Акцент» читают текущие цвета `Theme`;
  фиксированные тёмные цвета не используются.
- **Толщина рамки** — компактная строка с нативным `SeekBarView`, непрерывным
  диапазоном 0.5–3.0 dp, живым значением и сохранением после окончания
  перетаскивания.

В API настроек exteraless нет встроенного color picker, поэтому Botile
использует палитру, а не придумывает несуществующий элемент. Нативный
`SeekBarView` читает `NaConfig.sliderStyle` приложения (default, Modern или
MD3), поэтому контрол следует выбранному стилю; отдельного буквального флага
«MD3E» в этой сборке нет. Alpha 45% и максимальный радиус аватара 11 dp не
меняются. Значения применяются при следующей отрисовке аватара.

## Что делает плагин

- Бот определяется по `TLRPC.User`/`TLRPC.Chat`, переданному в
  `ImageReceiver.setForUserOrChat(...)`.
- Помеченным bot-получателям принудительно ставится радиус Botile через
  `ImageReceiver.setRoundRadius(int[])`. Исходный радиус всех четырёх углов,
  включая нули и асимметрию, сохраняется и восстанавливается.
- Профили и результаты поиска, передающие сущность через
  `ImageReceiver.setImage(..., parentObject=...)`, поддерживаются через узкий
  allowlist родительских классов.
- `setImageBitmap(...)` и пользовательские `setImage(...)` очищают состояние
  бота.
- После `ImageReceiver.draw(Canvas, BackgroundThreadDrawHolder)` добавляется
  обводка: 0.5–3.0 dp внутри границ изображения (по умолчанию 1 dp), по
  текущему радиусу. Цвет по умолчанию — адаптивный цвет текста темы; доступны
  пресеты «Акцент», «Белая» и «Чёрная». Не-боты отсекаются до вызова Python.
- При выгрузке все хуки снимаются, а сохранённые радиусы и метки
  восстанавливаются.

Форму аватаров не-ботов всегда задаёт клиент. Botile не заменяет изображение,
view, drawable или рендерер.

## Ограничения

- Векторные/видео-аватары профиля бота, задаваемые только через
  `setImageBitmap(...)`, не имеют сущности в точке вызова и могут быть не
  покрыты.
- Полноэкранные фото и уведомления не являются целями.
- Фоновые draw-вызовы с non-null holder пропускаются обводкой.
- Цвет рамки выбирается из пресетов, а не произвольным color picker: API
  настроек его не предоставляет.
- Адаптивная обводка использует глобальный цвет темы, а не per-chat
  `ResourcesProvider`.
- Включение Botile не вызывает глобальную перезагрузку списка; ячейки
  обновляются при следующей привязке или обновлении.
- Host-side моки не доказывают отрисовку Android. После изменений runtime нужна
  проверка на устройстве.

## Разработка

Достаточно Python 3.11 и стандартной библиотеки:

```bash
python3 -m py_compile Botile.plugin
python3 scripts/package_release.py --check
python3 tests/test_state_preservation.py
python3 scripts/package_release.py --output-dir dist
(cd dist && sha256sum -c SHA256SUMS)
```

Результат сборки:

```text
dist/Botile-1.2.0.plugin
dist/SHA256SUMS
```

Источник версии — метаданные плагина. Релизы запускаются по тегу: существующий
тег `vMAJOR.MINOR.PATCH` запускает проверки синтаксиса, метаданных и mock-тестов,
сверяет тег с `__version__`, собирает и проверяет контрольную сумму плагина,
затем публикует `Botile-<version>.plugin` и `SHA256SUMS` со сгенерированными
release notes. Workflow никогда не создаёт и не перемещает теги. Botile
распространяется по лицензии MIT; см. [LICENSE](LICENSE).

## Проверка на телефоне

После установки на exteraless:

1. Откройте основной список чатов с ботом, пользователем, группой и каналом.
2. У бота должен быть скруглённый квадрат с тонкой обводкой; пользователи,
   группы и каналы сохраняют форму и не имеют обводки Botile.
3. Откройте настройки Botile: переключите язык приложения между русским и
   английским и откройте экран заново; подписи и описания должны совпадать с
   активным языком.
4. Проверьте цветовые образцы и компактный слайдер толщины. Медленно
   перетащите его: ползунок и значение должны двигаться непрерывно, а стиль
   слайдера — соответствовать выбранному стилю приложения (включая MD3, если
   он включён). Выключите рамку и проверьте, что изменения применяются к ботам
   при следующей отрисовке.
5. Повторите в светлой и тёмной темах, в чате с ботом, профиле бота и превью
   пересланного сообщения/ответа. Прокрутите список для переиспользования ячеек.
6. Соберите `adb logcat` и скриншоты. Полезные строки:
   `diag hooks permission=True`, `hook bind: installed`,
   `hook border: installed draw outline`, `diag first bind: ... bot=True`.

В отчёте об ошибке укажите версию Botile, сборку/SDK exteraless, устройство и
Android, нужные строки журнала и скриншоты. Об уязвимостях сообщайте приватно
через GitHub Security Advisories, а не в публичном issue.
